# Трембіта CRM — Task Manager (Test Task)

Сучасна повнофункціональна система управління завданнями (**Full Stack: FastAPI + Vue 3**), розроблена в межах тестового завдання. Проєкт побудований за концепцією **Low-Code реєстрів (Config-driven UI)** та виконаний у фірмовій дизайн-системі **Дія**.

---

## 🚀 Технологічний стек

### **Backend**
* **Мова та фреймворк:** Python 3.11, FastAPI (асинхронна архітектура)
* **ORM та БД:** SQLAlchemy 2 (Asyncio + `asyncpg`), PostgreSQL 15
* **Міграції:** Alembic
* **Кешування та безпека:** Redis 7 (кешування та Blacklist JWT-токенів при виході)
* **Автентифікація:** JWT (PyJWT), Passlib (Bcrypt)
* **Валідація:** Pydantic v2 (Pydantic Settings, EmailStr)

### **Frontend**
* **Фреймворк:** Vue.js 3 (Composition API, `<script setup lang="ts">`)
* **Типізація:** TypeScript (строгий режим `vue-tsc`)
* **Збірка:** Vite
* **Стилізація:** Tailwind CSS 3, дизайн-система **Дія** (`#1C1C1E`, `#F5F5F7`, `#C6F150`)
* **Стейт-менеджмент:** Pinia
* **Маршрутизація:** Vue Router 4 (з Navigation Guards для захисту маршрутів)
* **HTTP-клієнт:** Axios (інтерцептори для автоматичного підставлення Bearer токена)

### **Інфраструктура**
* **Контейнеризація:** Docker, docker-compose (мультиконтейнерне середовище: `db`, `redis`, `backend`, `frontend`)

---

## ✨ Ключовий функціонал системи

1. 🔐 **Повноцінна автентифікація та профіль користувача**:
   * Реєстрація з введенням повних даних (Прізвище, Ім'я, По батькові, Email, Пароль).
   * Авторизація за JWT-токеном (OAuth2 Password Bearer).
   * Безпечний вихід (`/auth/logout`) з додаванням активного токена у **Redis Blacklist**.
   * Відображення ПІБ та email користувача у бічній панелі.

2. 📊 **Аналітична панель моніторингу (`/about`)**:
   * Динамічні картки ключових показників (KPI): «Всього задач», «В процесі», «На QA», «Виконано», «Заблоковано», «Прострочено».
   * Режими перегляду: **Порівняння** (Загальні vs Мої задачі), **Загальна система**, **Мої задачі**.
   * Графіки розподілу за статусами та пріоритетами, контроль прострочених дедлайнів.

3. 📑 **Low-Code Реєстр задач (`/tasks`)**:
   * **Config-driven архітектура** (`tasksRegistry.ts`): конфігурація колонок, типи даних (`text`, `textarea`, `select`, `badge`, `date`, `number`), плейсхолдери, сортування та обов'язковість.
   * **Кастомний компонент випадалок (`RegistrySelect`)**: замінює нативний браузерний select на фірмовий Дія-дропдаун з іконками та бейджами класифікаторів. Використовується як у фільтрах, так і у формах.
   * **Кастомний компонент календаря (`RegistryDatePicker`)**: локалізований вибір дати та часу (години/хвилини, пресети `09:00`, `13:00`, `18:00`, `23:59`) з адаптивним відкриттям.
   * **Універсальна таблиця**: серверний пошук, комбінована фільтрація за статусом і пріоритетом, клікабельне сортування за колонками.
   * **Повний CRUD**: створення та редагування задач у модальному вікні, підтвердження видалення (`RegistryDeleteModal`), реактивні тост-сповіщення (`RegistryToast`).
   * **Пагінація (`RegistryPagination`)**: вибір кількості рядків на сторінці (10, 25, 50, 100), навігація по сторінках.

## 🛠 Інструкція з локального запуску

### 1. Передумови
* Встановлений [Docker Desktop](https://www.docker.com/products/docker-desktop/) (або Docker Engine + docker-compose).
* Встановлений `git`.

### 2. Клонування репозиторію
```bash
git clone https://github.com/FarizovM/diia_test_task.git
cd diia_test_task
```

### 3. Запуск контейнерів
Зберіть та запустіть усі сервіси (`task_manager_db`, `task_manager_redis`, `task_manager_backend`, `task_manager_frontend`) у фоновому режимі:

```bash
docker-compose up --build -d
```

Зачекайте кілька секунд, доки база даних PostgreSQL завершить ініціалізацію.

### 4. Застосування міграцій бази даних
Створіть схему таблиць у PostgreSQL через Alembic всередині контейнера бекенду:

```bash
docker exec -it task_manager_backend alembic upgrade head
```

### 5. Генерація тестових даних (Seeding)
Запустіть скрипт, який створить тестового адміністратора та 20 задач із різними пріоритетами, статусами та дедлайнами:

```bash
docker exec -it task_manager_backend python seed.py
```

@app.middleware("http")
async def log_requests_middleware(request: Request, call_next):
    start_time = time.perf_counter()
    client_ip = request.client.host if request.client else "unknown"
    
    try:
        response = await call_next(request)
        process_time = (time.perf_counter() - start_time) * 1000
        
        log_msg = (
            f"{client_ip} - \"{request.method} {request.url.path}\" "
            f"Status: {response.status_code} - {process_time:.2f}ms"
        )
        
        if response.status_code >= 400:
            logger.warning(log_msg)
        else:
            logger.info(log_msg)
            
        return response
    except Exception as exc:
        process_time = (time.perf_counter() - start_time) * 1000
        logger.error(
            f"{client_ip} - \"{request.method} {request.url.path}\" "
            f"FAILED after {process_time:.2f}ms: {exc}",
            exc_info=True,
        )
        return JSONResponse(
            status_code=500,
            content={"detail": "Internal server error"},
        )

async def get_current_user(
    token: str = Depends(oauth2_scheme), 
    db: AsyncSession = Depends(get_db),
    redis: Redis = Depends(get_redis)
) -> User:
    credentials_exception = HTTPException(
        status_code=status.HTTP_401_UNAUTHORIZED,
        detail="Could not validate credentials",
        headers={"WWW-Authenticate": "Bearer"},
    )

    is_blacklisted = await redis.get(f"bl_{token}")
    if is_blacklisted:
         raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Token has been revoked (logged out)",
            headers={"WWW-Authenticate": "Bearer"},
        )

    try:
        payload = jwt.decode(token, settings.SECRET_KEY, algorithms=[settings.ALGORITHM])
        user_id: str = payload.get("sub")
        if user_id is None:
            raise credentials_exception
    except InvalidTokenError:
        raise credentials_exception

    result = await db.execute(select(User).where(User.user_id == user_id))
    user = result.scalars().first()
    if user is None:
        raise credentials_exception
    return user

    description="Автентифікація користувача за стандартом OAuth2 Password Request. У полі 'username' необхідно передавати email користувача. Повертає підписаний JWT Bearer токен для подальших запитів.",
    response_description="Access токен з типом 'bearer'",
    responses={
        401: {"description": "Невірний логін (email) або пароль"},
        422: {"description": "Помилка валідації вхідної форми"}
    }
)
async def login(
    form_data: OAuth2PasswordRequestForm = Depends(),
    db: AsyncSession = Depends(get_db)
):
    
    logger.info(f"Спроба входу користувача - {form_data.username}")

    # У OAuth2PasswordRequestForm поле називається username, але ми передаємо туди email
    result = await db.execute(select(User).where(User.email == form_data.username))
    user = result.scalars().first()
    
    # Перевірка наявності користувача та правильності пароля
    if not user or not verify_password(form_data.password, user.hashed_password):
        logger.error(f"Користувач з email {form_data.username} не існує або пароль невірний")
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Невірний логін або пароль",
            headers={"WWW-Authenticate": "Bearer"},
        )
    
    access_token = create_access_token(data={"sub": user.user_id})
    
    logger.info(f"Користувач {user.user_id} успішно авторизований. Токен створено")
    
    return {"access_token": access_token, "token_type": "bearer"}

async def get_tasks(
    search: Optional[str] = Query(
        None, 
        description="Пошуковий запит (пошук підрядка в назві або описі)", 
        examples=["підпис"]
    ),
    status: Optional[TaskStatus] = Query(
        None, 
        description="Фільтр за статусом задачі", 
        examples=[TaskStatus.IN_PROGRESS]
    ),
    priority: Optional[TaskPriority] = Query(
        None, 
        description="Фільтр за пріоритетом задачі", 
        examples=[TaskPriority.HIGH]
    ),
    deadline: Optional[date] = Query(
        None, 
        description="Фільтр за точною датою дедлайну (РРРР-ММ-ДД)", 
        examples=["2026-10-31"]
    ),
    limit: Optional[int] = Query(
        default=10, 
        ge=1, 
        le=100, 
        description="Кількість задач на сторінці (від 1 до 100)", 
        examples=[10]
    ),
    page: Optional[int] = Query(
        default=1, 
        ge=1, 
        description="Номер сторінки (починається з 1)", 
        examples=[1]
    ),
    sort_by: Optional[str] = Query(
        default="created_at", 
        description="Поле для сортування (created_at, deadline, priority, status, title)", 
        examples=["created_at"]
    ),
    sort_order: Optional[SortOrder] = Query(
        default=SortOrder.DESC, 
        description="Напрямок сортування ('asc' або 'desc')", 
        examples=[SortOrder.DESC]
    ),
    db: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    if page < 1: 
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST, 
            detail="Сторінка має бути більшою за 0"
        )

    if limit < 1: 
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST, 
            detail="Ліміт має бути більшим за 0"
        )

    if sort_order not in ["asc", "desc"]: 
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST, 
            detail="Порядок сортування має бути 'asc' або 'desc'"
        )

    sort_field = getattr(Task, sort_by, None)
    if not sort_field: 
        raise HTTPException(
            status_code=status.HTTP_400_BAD_REQUEST, 
            detail="Сортування за цим полем не підтримується"
        )
    
    order_clause = sort_field.desc() if sort_order == "desc" else sort_field.asc()
    
    offset = limit * (page - 1)
    

    base_query = select(Task).where(Task.created_by == current_user.user_id)

    total = (
        await db.execute(
            select(func.count(Task.task_id)).where(Task.created_by == current_user.user_id)
        )
    ).scalar() or 0

    query = base_query
    if status:
        query = query.where(Task.status == status)
    if priority:
        query = query.where(Task.priority == priority)
    if deadline:
        query = query.where(cast(Task.deadline, Date) == deadline)
    if search:
        query = query.where(
            or_(
                Task.title.ilike(f"%{search}%"),
                Task.description.ilike(f"%{search}%")
            )
        )

    filtered = (
        await db.execute(
            select(func.count()).select_from(query.subquery())
        )
    ).scalar() or 0
        
    query = query.order_by(order_clause).limit(limit).offset(offset)    

    result = await db.execute(query)

    tasks = result.scalars().all()

    return TaskRegistryResponse(
        total=total,
        filtered=filtered,
        rows=tasks
    )

from datetime import datetime
import logging
from logging.handlers import RotatingFileHandler
from pathlib import Path

LOG_DIR = Path(__file__).resolve().parent.parent.parent / "logs"
LOG_DIR.mkdir(exist_ok=True)

LOG_FORMAT = "%(asctime)s | %(levelname)-8s | %(name)s | %(module)s.%(funcName)s:%(lineno)d | %(message)s"
DATE_FORMAT = "%Y-%m-%d %H:%M:%S"


class FunctionDateErrorFileHandler(logging.Handler):
    """
    Кастомний обробник для запису помилок (ERROR та вище)
    у структуру: logs/<назва_функції>/<YYYY-MM-DD>.log
    """
    def __init__(self, base_dir: Path, level=logging.ERROR):
        super().__init__(level=level)
        self.base_dir = base_dir

    def emit(self, record: logging.LogRecord) -> None:
        try:
            if record.levelno < logging.ERROR:
                return

            func_name = record.funcName or "root"
            date_str = datetime.now().strftime("%Y-%m-%d")

            # Папка з назвою функції: logs/<назва_функції>/
            func_dir = self.base_dir / func_name
            func_dir.mkdir(parents=True, exist_ok=True)

            log_file = func_dir / f"{date_str}.log"
            msg = self.format(record)

            with open(log_file, "a", encoding="utf-8") as f:
                f.write(msg + "\n")
        except Exception:
            self.handleError(record)


def setup_logger(name: str = "diia_test_task_app") -> logging.Logger:
    logger = logging.getLogger(name)
    logger.setLevel(logging.INFO)
    if logger.handlers:
        return logger

    formatter = logging.Formatter(LOG_FORMAT, datefmt=DATE_FORMAT)

    # Загальний лог роботи застосунку (макс. 5 МБ, зберігаємо 10 файлів)
    info_handler = RotatingFileHandler(
        LOG_DIR / "app.log",
        maxBytes=5 * 1024 * 1024,
        backupCount=10,
        encoding="utf-8",
    )
    info_handler.setLevel(logging.INFO)
    info_handler.setFormatter(formatter)

    # Логування помилок за структурою: logs/<назва_функції>/<YYYY-MM-DD>.log
    error_handler = FunctionDateErrorFileHandler(LOG_DIR, level=logging.ERROR)
    error_handler.setFormatter(formatter)

    # Вивід у консоль Docker
    console_handler = logging.StreamHandler()
    console_handler.setLevel(logging.INFO)
    console_handler.setFormatter(formatter)

    logger.addHandler(info_handler)
    logger.addHandler(error_handler)
    logger.addHandler(console_handler)

    return logger


logger = setup_logger()

    if expires_delta:

import urllib.parse
from starlette.middleware.base import BaseHTTPMiddleware
from starlette.requests import Request
from starlette.responses import JSONResponse, Response
from app.core.config import settings
from app.core.logger import logger

MUTATING_METHODS = {"POST", "PUT", "PATCH", "DELETE"}

class SecurityHeadersMiddleware(BaseHTTPMiddleware):
    """
    Middleware для забезпечення безпеки HTTP-заголовків:
    1. Перевірка Origin та Referer для запитів, що модифікують стан (CSRF & Cross-Origin захист).
    2. Додавання захисних HTTP-заголовків у відповіді (X-Frame-Options, X-Content-Type-Options,
       Referrer-Policy, Content-Security-Policy, Permissions-Policy).
    """

    async def dispatch(self, request: Request, call_next):
        # Валідація Origin / Referer для мутуючих методів (POST, PUT, PATCH, DELETE)
        if request.method in MUTATING_METHODS:
            origin = request.headers.get("origin")
            referer = request.headers.get("referer")

            # Перевірка заголовка Origin (якщо запит ініційовано браузером/CORS)
            if origin:
                if origin not in settings.ALLOWED_ORIGINS:
                    logger.warning(
                        f"Заблоковано запит з недійсним Origin: '{origin}' | "
                        f"Метод: {request.method} | Шлях: {request.url.path}"
                    )
                    return JSONResponse(
                        status_code=403,
                        content={"detail": "Доступ заборонено: недійсний заголовок Origin"},
                    )

            # Якщо Origin відсутній, але передано Referer
            elif referer:
                parsed_ref = urllib.parse.urlsplit(referer)
                ref_origin = f"{parsed_ref.scheme}://{parsed_ref.netloc}"
                if ref_origin not in settings.ALLOWED_ORIGINS:
                    logger.warning(
                        f"Заблоковано запит з недійсним Referer: '{referer}' (джерело: {ref_origin}) | "
                        f"Метод: {request.method} | Шлях: {request.url.path}"
                    )
                    return JSONResponse(
                        status_code=403,
                        content={"detail": "Доступ заборонено: недійсний заголовок Referer"},
                    )

        # Обробка основного запиту
        response: Response = await call_next(request)

        # Встановлення захисних HTTP-заголовків (Security Response Headers)
        response.headers["X-Frame-Options"] = "DENY"
        response.headers["X-Content-Type-Options"] = "nosniff"
        response.headers["Referrer-Policy"] = "strict-origin-when-cross-origin"
        response.headers["X-XSS-Protection"] = "1; mode=block"
        response.headers["Permissions-Policy"] = "geolocation=(), camera=(), microphone=(), payment=()"

        # Налаштування Content Security Policy (CSP)
        # Для сторінок інтерактивної документації OpenAPI дозволяємо CDN стилів та скриптів
        if request.url.path in ("/docs", "/redoc", "/api/v1/openapi.json"):
            response.headers["Content-Security-Policy"] = (
                "default-src 'self'; "
                "script-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net; "
                "style-src 'self' 'unsafe-inline' https://cdn.jsdelivr.net; "
                "img-src 'self' data: https://fastapi.tiangolo.com; "
                "frame-ancestors 'none';"
            )
        else:
            response.headers["Content-Security-Policy"] = (
                "default-src 'self'; "
                "frame-ancestors 'none';"
            )

        return response

from datetime import datetime, timezone
from sqlalchemy import text
from sqlalchemy.ext.asyncio import AsyncSession
from redis.asyncio import Redis

from app.schemas.stats import TaskStats
from app.core.logger import logger

STATS_ALL_KEY = "stats:all"
STATS_USER_KEY_PREFIX = "stats:user:"
STATS_CACHE_TTL = 600  # 10 хвилин

def get_stats_user_key(user_id: str) -> str:
    return f"{STATS_USER_KEY_PREFIX}{user_id}"

STATS_BASE_SQL = """
    select
        count(*) as total,
        count(*) filter (where upper(cast(status as text)) = 'TODO') as todo,
        count(*) filter (where upper(cast(status as text)) = 'IN_PROGRESS') as in_progress,
        count(*) filter (where upper(cast(status as text)) = 'QA') as qa,
        count(*) filter (where upper(cast(status as text)) = 'DONE') as done,
        count(*) filter (where upper(cast(status as text)) = 'FLAGGED') as flagged,
        count(*) filter (where upper(cast(priority as text)) = 'LOWEST') as lowest,
        count(*) filter (where upper(cast(priority as text)) = 'LOW') as low,
        count(*) filter (where upper(cast(priority as text)) = 'MEDIUM') as medium,
        count(*) filter (where upper(cast(priority as text)) = 'HIGH') as high,
        count(*) filter (where upper(cast(priority as text)) = 'HIGHEST') as highest,
        count(*) filter (where deadline is null) as no_deadline,
        count(*) filter (where deadline is not null) as has_deadline,
        count(*) filter (where deadline < :now_val and upper(cast(status as text)) != 'DONE') as overdue
    from tasks
"""

async def calculate_stats_all(db: AsyncSession) -> TaskStats:
    """Обчислення глобальної статистики напряму з бази даних"""
    stmt = text(STATS_BASE_SQL)
    result = await db.execute(stmt, {"now_val": datetime.now(timezone.utc)})
    row = result.mappings().first()
    return TaskStats(**dict(row))

async def calculate_stats_user(db: AsyncSession, user_id: str) -> TaskStats:
    """Обчислення статистики конкретного користувача напряму з бази даних"""
    stmt = text(STATS_BASE_SQL + " where created_by = :user_id")
    result = await db.execute(stmt, {"now_val": datetime.now(timezone.utc), "user_id": user_id})
    row = result.mappings().first()
    return TaskStats(**dict(row))

async def get_stats_all_cached(db: AsyncSession, redis: Redis) -> TaskStats:
    """Отримання глобальної статистики з кешу Redis (Cache-Aside pattern)"""
    try:
        cached = await redis.get(STATS_ALL_KEY)
        if cached:
            logger.info("Глобальну статистику /stats/all отримано з кешу Redis")
            return TaskStats.model_validate_json(cached)
    except Exception as e:
        logger.warning(f"Помилка читання кешу stats:all з Redis: {e}")

    stats = await calculate_stats_all(db)

    try:
        await redis.setex(STATS_ALL_KEY, STATS_CACHE_TTL, stats.model_dump_json())
    except Exception as e:
        logger.warning(f"Помилка збереження кешу stats:all в Redis: {e}")

    return stats

async def get_stats_user_cached(db: AsyncSession, redis: Redis, user_id: str) -> TaskStats:
    """Отримання персональної статистики користувача з кешу Redis"""
    key = get_stats_user_key(user_id)
    try:
        cached = await redis.get(key)
        if cached:
            logger.info(f"Персональну статистику /stats/me для {user_id} отримано з кешу Redis")
            return TaskStats.model_validate_json(cached)
    except Exception as e:
        logger.warning(f"Помилка читання кешу {key} з Redis: {e}")

    stats = await calculate_stats_user(db, user_id)

    try:
        await redis.setex(key, STATS_CACHE_TTL, stats.model_dump_json())
    except Exception as e:
        logger.warning(f"Помилка збереження кешу {key} в Redis: {e}")

    return stats

async def update_stats_cache(db: AsyncSession, redis: Redis, user_id: str) -> None:
    """
    Оновлення кешу статистики в Redis при мутаціях задач (створення, редагування, видалення).
    Оновлює як загальну статистику системи, так і персональну статистику автора задачі.
    """
    try:
        stats_all = await calculate_stats_all(db)
        await redis.setex(STATS_ALL_KEY, STATS_CACHE_TTL, stats_all.model_dump_json())

        stats_user = await calculate_stats_user(db, user_id)

        logger.info(f"Кеш статистики в Redis успішно оновлено для користувача {user_id} та stats:all")
    except Exception as e:
        logger.warning(f"Не вдалося оновити кеш статистики в Redis: {e}")

  })

  () => props.isOpen,
  (open) => {
    if (open) {
      document.documentElement.classList.add('overflow-hidden')
      document.body.classList.add('overflow-hidden')
      localError.value = ''
      const data: Record<string, any> = {}

      editableColumns.value.forEach((col) => {
        if (props.mode === 'edit' && props.initialData) {
          let val = props.initialData[col.key]
          // Якщо поле дати, конвертуємо в формат для input datetime-local YYYY-MM-DDTHH:mm
          if (col.type === 'date' && val) {
            try {
              const d = new Date(val)
              val = new Date(d.getTime() - d.getTimezoneOffset() * 60000)
                .toISOString()
                .slice(0, 16)
            } catch {
              // ignore
            }
          }
          data[col.key] = val ?? ''
        } else {
          // Для нового запису: перевіряємо defaultValue, далі options для select, або порожній рядок
          if (col.defaultValue !== undefined) {
            data[col.key] = col.defaultValue
          } else if (col.options && col.options.length > 0) {
            data[col.key] = col.options[0].key || ''
          } else {
            data[col.key] = ''
          }
        }
      })

      formData.value = data
    } else {
      document.documentElement.classList.remove('overflow-hidden')
      document.body.classList.remove('overflow-hidden')
    }
  },

      }

        payload[col.key] = Number(payload[col.key])
      } else {
        payload[col.key] = null
      }
    }
  })

  emit('submit', payload)

  placeholder?: string
  required?: boolean
  disabled?: boolean

}>()

}>()

const isOpen = ref(false)
const selectRoot = ref<HTMLElement | null>(null)
const dropdownMenu = ref<HTMLElement | null>(null)
const dropdownStyle = ref<Record<string, string>>({})

  if (props.modelValue === undefined || props.modelValue === null) {
    return null
  }
  const valStr = String(props.modelValue).toLowerCase()
  return (
    props.options.find(
      (opt) => String(opt.key).toLowerCase() === valStr
    ) || null
  )
})

function isSelected(opt: SelectOption<any>): boolean {
  if (props.modelValue === undefined || props.modelValue === null) return false
  const optVal = String(opt.key).toLowerCase()
  return String(props.modelValue).toLowerCase() === optVal
}

function updateDropdownPosition() {
  if (!selectRoot.value) return
  const rect = selectRoot.value.getBoundingClientRect()
  const spaceBelow = window.innerHeight - rect.bottom
  const spaceAbove = rect.top
  const openUpward = spaceBelow < 250 && spaceAbove > spaceBelow

  const style: Record<string, string> = {
    position: 'fixed',
    left: `${rect.left}px`,
    width: `${rect.width}px`,
    zIndex: '9999',
  }

  if (openUpward) {
    style.bottom = `${window.innerHeight - rect.top + 6}px`
    style.top = 'auto'
  } else {
    style.top = `${rect.bottom + 6}px`
    style.bottom = 'auto'
  }

  dropdownStyle.value = style
}

function toggleDropdown() {
  if (props.disabled) return
  if (!isOpen.value) {
    updateDropdownPosition()
    isOpen.value = true
  } else {
    isOpen.value = false
  }
}

function onScrollOrResize() {
  if (isOpen.value) {
    updateDropdownPosition()
  }
}

watch(isOpen, (open) => {
  if (open) {
    updateDropdownPosition()
    window.addEventListener('resize', onScrollOrResize)
    window.addEventListener('scroll', onScrollOrResize, true)
  } else {
    window.removeEventListener('resize', onScrollOrResize)
    window.removeEventListener('scroll', onScrollOrResize, true)

import { ref, computed } from 'vue'
import { defineStore } from 'pinia'
import type { AxiosError } from 'axios'
import api from '../api/axios'
import type { User, AuthTokenResponse, UserRegisterPayload } from '../types/models'

export const useAuthStore = defineStore('auth', () => {
    const user = ref<User | null>(null)
    const token = ref<string | null>(localStorage.getItem('access_token'))
    const loading = ref<boolean>(false)
    const error = ref<string | null>(null)

    const isAuthenticated = computed<boolean>(() => !!token.value)

    async function login(email: string, password: string): Promise<boolean> {
        loading.value = true
        error.value = null
        try {
            const formData = new URLSearchParams()
            formData.append('username', email)
            formData.append('password', password)

            const { data } = await api.post<AuthTokenResponse>('/auth/login', formData, {
                headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
            })

            token.value = data.access_token
            localStorage.setItem('access_token', data.access_token)
            await fetchUser()
            return true
        } catch (err) {
            const axiosErr = err as AxiosError<{ detail?: string }>
            error.value = axiosErr.response?.data?.detail || 'Помилка авторизації'
            return false
        } finally {
            loading.value = false
        }
    }

    async function register(payload: UserRegisterPayload): Promise<boolean> {
        loading.value = true
        error.value = null
        try {
            await api.post<User>('/auth/register', payload)
            return await login(payload.email, payload.password)
        } catch (err) {
            const axiosErr = err as AxiosError<{ detail?: string | any[] }>
            const detail = axiosErr.response?.data?.detail
            if (typeof detail === 'string') {
                error.value = detail
            } else if (Array.isArray(detail) && detail.length > 0) {
                error.value = detail
                    .map((e: any) => {
                        const raw = String(e.msg || e.message || '')
                        return raw.replace(/^Value error,\s*/i, '')
                    })
                    .join(', ')
            } else {
                error.value = 'Помилка реєстрації'
            }
            return false
        } finally {
            loading.value = false
        }
    }

    async function fetchUser(): Promise<void> {
        if (!token.value) return
        try {
            const { data } = await api.get<User>('/users/me')
            user.value = data
        } catch {
            user.value = null
        }
    }

    async function logout(): Promise<void> {
        try {
            if (token.value) {
                await api.post('/auth/logout')
            }
        } catch (e) {
            console.warn('Logout error:', e)
        } finally {
            token.value = null
            user.value = null
            localStorage.removeItem('access_token')
        }
    }

    return {
        user,
        token,
        loading,
        error,
        isAuthenticated,
        login,
        register,
        fetchUser,
        logout,
    }
})

<script setup lang="ts">
import { ref, computed } from 'vue'
import { useRouter } from 'vue-router'
import { useAuthStore } from '../stores/auth'

const authStore = useAuthStore()
const router = useRouter()

const isRegister = ref<boolean>(false)
const showPassword = ref<boolean>(false)

const firstName = ref<string>('')
const lastName = ref<string>('')
const middleName = ref<string>('')
const email = ref<string>('')
const password = ref<string>('')

// Критерії валідації пароля
const hasMinLength = computed<boolean>(() => password.value.length >= 8)
const hasLetter = computed<boolean>(() => /[a-zA-Z]/.test(password.value))
const hasDigit = computed<boolean>(() => /\d/.test(password.value))
const isPasswordValid = computed<boolean>(() => hasMinLength.value && hasLetter.value && hasDigit.value)

function toggleMode() {
    isRegister.value = !isRegister.value
    authStore.error = null
}

const handleSubmit = async (): Promise<void> => {
    if (!email.value.trim() || !password.value) return

    let success = false
    if (isRegister.value) {
        if (!lastName.value.trim()) {
            authStore.error = "Будь ласка, вкажіть прізвище"
            return
        }
        if (!firstName.value.trim()) {
            authStore.error = "Будь ласка, вкажіть ім'я"
            return
        }
        if (!isPasswordValid.value) {
            authStore.error = "Пароль не відповідає всім вимогам безпеки"
            return
        }

        success = await authStore.register({
            email: email.value.trim(),
            password: password.value,
            first_name: firstName.value.trim(),
            last_name: lastName.value.trim(),
            middle_name: middleName.value.trim() || null,
        })
    } else {
        success = await authStore.login(email.value.trim(), password.value)
    }

    if (success) {
        router.push('/about')
    }
}

            :is-submitting="isSubmitting" @close="isRowModalOpen = false" @submit="handleRowSubmit" />

        <!-- Модалка підтвердження видалення -->
        <RegistryDeleteModal :is-open="isDeleteModalOpen" :item-title="rowToDelete?.title || rowToDelete?.name || ''"
            :is-deleting="isDeleting" @close="isDeleteModalOpen = false" @confirm="handleConfirmDelete" />

        <!-- Сповіщення Toast -->
        <RegistryToast :message="toastMessage" :type="toastType" @close="toastMessage = ''" />
    </div>
</template>

<script setup lang="ts">
import { ref, computed, watch, nextTick } from 'vue'
import { useRoute } from 'vue-router'
import api from '../api/axios'

import type {
    RegistryConfig,
    RegistryResponse,
    RegistryFilter,
    RegistryColumn,
} from '../types/config'

import RegistryHeader from '../components/registry/RegistryHeader.vue'
import RegistryToolbar from '../components/registry/RegistryToolbar.vue'
import RegistryTable from '../components/registry/RegistryTable.vue'
import RegistryPagination from '../components/registry/RegistryPagination.vue'
import RegistryRowModal from '../components/registry/RegistryRowModal.vue'
import RegistryDeleteModal from '../components/registry/RegistryDeleteModal.vue'
import RegistryToast from '../components/registry/RegistryToast.vue'

const route = useRoute()

// Визначаємо alias з маршруту
const alias = computed(() => {
    const parts = route.path.split('/').filter(Boolean)
    return parts[parts.length - 1] || ''
})

// Стан конфігурації
const registryConfig = ref<RegistryConfig | null>(null)
const isLoadingConfig = ref<boolean>(true)
const configError = ref<string | null>(null)

// Дані таблиці
const rows = ref<any[]>([])
const total = ref<number>(0)
const filtered = ref<number>(0)
const isTableLoading = ref<boolean>(false)

// Фільтри та пагінація
const currentPage = ref<number>(1)
const pageSize = ref<number>(10)
const sortBy = ref<string>('created_at')
const sortOrder = ref<'asc' | 'desc'>('desc')
const searchQuery = ref<string>('')
const activeFilters = ref<Record<string, string>>({})

const columns = ref<RegistryColumn[]>([])
const registryFilters = ref<RegistryFilter[]>([])

// Стан модалок
const isRowModalOpen = ref<boolean>(false)
const modalMode = ref<'create' | 'edit'>('create')
const selectedRow = ref<any>(null)
const isSubmitting = ref<boolean>(false)

const isDeleteModalOpen = ref<boolean>(false)
const rowToDelete = ref<any>(null)
const isDeleting = ref<boolean>(false)

// Стан тостів
const toastMessage = ref<string>('')
const toastType = ref<'success' | 'error'>('success')

let toastTimer: any = null
function showToast(msg: string, type: 'success' | 'error' = 'success') {
    toastMessage.value = msg
    toastType.value = type
    clearTimeout(toastTimer)
    toastTimer = setTimeout(() => {
        toastMessage.value = ''
    }, 4000)
}

function getBaseEndpoint(): string {
    const ep = registryConfig.value?.endpoint || ''
    if (!ep) return ''
    return ep.endsWith('/') ? ep : `${ep}/`
}

function getRowId(row: any): string {
    return row?.task_id || row?.id || row?._id || ''
}

// Завантаження даних з бекенду
async function loadData() {
    const endpoint = getBaseEndpoint()
    if (!endpoint) return

    isTableLoading.value = true

    try {
        const params: Record<string, any> = {
            page: currentPage.value,
            limit: pageSize.value,
            sort_by: sortBy.value,
            sort_order: sortOrder.value,
            ...activeFilters.value,
        }

        if (searchQuery.value.trim()) {
            params.search = searchQuery.value.trim()
        }

        const { data } = await api.get<RegistryResponse>(endpoint, { params })

        if (data && Array.isArray(data.rows)) {
            total.value = data.total
            filtered.value = data.filtered
            rows.value = data.rows
        } else {
            total.value = 0
            filtered.value = 0
            rows.value = []
        }
    } catch (err: any) {
        console.error('Failed to load table data:', err)
        showToast('Не вдалося завантажити дані реєстру', 'error')
    } finally {
        isTableLoading.value = false
    }
}

// Оновлення даних користувачем
function refreshData() {
    loadData()
}

// Сортування стовпця
function handleSort(columnKey: string) {
    if (sortBy.value === columnKey) {
        sortOrder.value = sortOrder.value === 'asc' ? 'desc' : 'asc'
    } else {
        sortBy.value = columnKey
        sortOrder.value = 'asc'
    }
    currentPage.value = 1
    loadData()
}

// Скидання фільтрів
function resetFilters() {
    searchQuery.value = ''
    currentPage.value = 1
    if (Object.keys(activeFilters.value).length > 0) {
        activeFilters.value = {}
    } else {
        loadData()
    }
}

// Слідкуємо за зміною сторінки або ліміту
watch([currentPage, pageSize], () => {
    if (isLoadingConfig.value) return
    loadData()
})

// Слідкуємо за фільтрами
watch(activeFilters, () => {
    if (isLoadingConfig.value) return
    currentPage.value = 1
    loadData()
}, { deep: true })

// Слідкуємо за пошуком із debounce
let searchDebounce: any = null
watch(searchQuery, () => {
    if (isLoadingConfig.value) return
    clearTimeout(searchDebounce)
    searchDebounce = setTimeout(() => {
        currentPage.value = 1
        loadData()
    }, 350)
})

// Відкриття модалок
function openCreateModal() {
    modalMode.value = 'create'
    selectedRow.value = null
    isRowModalOpen.value = true
}

function openEditModal(row: any) {
    modalMode.value = 'edit'
    selectedRow.value = { ...row }
    isRowModalOpen.value = true
}

function openDeleteModal(row: any) {
    rowToDelete.value = row
    isDeleteModalOpen.value = true
}

// Створення або редагування запису
async function handleRowSubmit(formData: Record<string, any>) {
    const baseEp = getBaseEndpoint()
    if (!baseEp) return

    isSubmitting.value = true
    try {
        if (modalMode.value === 'create') {
            await api.post(baseEp, formData)
            showToast('Запис успішно створено!', 'success')
        } else {
            const id = getRowId(selectedRow.value)
            await api.put(`${baseEp}${id}`, formData)
            showToast('Запис успішно оновлено!', 'success')
        }

        isRowModalOpen.value = false
        await loadData()
    } catch (err: any) {
        console.error('Failed to submit row:', err)
        const detail = err.response?.data?.detail
        const msg = typeof detail === 'string' ? detail : 'Помилка при збереженні запису'
        showToast(msg, 'error')
    } finally {
        isSubmitting.value = false
    }
}

// Видалення запису
async function handleConfirmDelete() {
    const baseEp = getBaseEndpoint()
    if (!baseEp || !rowToDelete.value) return

    const id = getRowId(rowToDelete.value)
    if (!id) return

    isDeleting.value = true
    try {
        await api.delete(`${baseEp}${id}`)
        showToast('Запис успішно видалено', 'success')
        isDeleteModalOpen.value = false
        rowToDelete.value = null
        await loadData()
    } catch (err: any) {
        console.error('Failed to delete row:', err)
        const detail = err.response?.data?.detail
        const msg = typeof detail === 'string' ? detail : 'Помилка при видаленні запису'
        showToast(msg, 'error')
    } finally {
        isDeleting.value = false
    }
}

// Динамічний пошук конфігів реєстрів (.ts)
const registryModules = import.meta.glob<{ default: RegistryConfig }>([
    '../config/*Registry.ts',
])

// Завантаження конфігу реєстру (tasksRegistry.ts тощо)
async function loadConfig(name: string) {
    if (!name) return
    configError.value = null

    try {
        const tsKey = `../config/${name}Registry.ts`

        const loader = registryModules[tsKey];
        if (!loader) {
            throw new Error(`Конфігурацію для "${name}" не знайдено`)
        }

        const module = await loader()
        registryConfig.value = module.default
        document.title = `${registryConfig.value?.title || name} | ДІЯ`

        columns.value = registryConfig.value?.columns || []
        registryFilters.value = registryConfig.value?.filters || []
        sortBy.value = registryConfig.value?.defaultSort?.sortBy || 'created_at'
        sortOrder.value = registryConfig.value?.defaultSort?.sortOrder || 'desc'

        currentPage.value = 1
        if (Object.keys(activeFilters.value).length > 0) {
            activeFilters.value = {}
        }
        searchQuery.value = ''

        await nextTick()
        isLoadingConfig.value = false

        await loadData()
    } catch (err) {
        console.error(`Failed to load config for: ${name}`, err)
        configError.value = `Конфігурацію для "${name}" не знайдено`
        registryConfig.value = null
        isLoadingConfig.value = false
    }
}

// Слідкуємо за зміною маршруту для завантаження конфігу
watch(
    alias,
    (newAlias) => {
        loadConfig(newAlias)
    },
    { immediate: true }
)
</script>
